# Salman Ali - Portfolio Website

A modern, responsive portfolio website built with React and Vite.

## 🚀 Live Demo

**[View Portfolio](https://salmanmani86.github.io/portfolio)**

## ✨ Features

- Modern dark theme with amber accents
- Fully responsive design
- Smooth scroll animations (Framer Motion)
- Interactive skill bars with filtering
- Timeline-based experience section
- Project showcase with GitHub links
- Downloadable resume
- Contact section with social links

## 🛠️ Tech Stack

- React 18
- Vite
- Framer Motion
- CSS3 with CSS Variables

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/SalmanMani86/portfolio.git

# Navigate to directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🚀 Deployment

This site auto-deploys to GitHub Pages via GitHub Actions when you push to `main`.

Manual deployment:
```bash
npm run deploy
```
